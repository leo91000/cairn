# Cairn et Beacon avant la première release

Décision de Léo, 2026-10-09 : le produit et les comptes portent le nom **Cairn** ; le service hébergé est **Beacon**, sur `cairn.build`. Les dossiers, binaires, images, outils invités et identifiants sont renommés ensemble avant une installation neuve, afin de ne pas imposer de migration ni d’alias aux futurs clients. L’identité choisie est la piste B · Balise : bleu de Prusse, deux pierres et un feu ocre en losange ; l’ocre est réservé à la marque.

Les ADR antérieures restent des traces historiques. Le dépôt GitHub conserve son nom actuel jusqu’à son renommage manuel par Léo ; cette action est distincte du renommage du produit.
